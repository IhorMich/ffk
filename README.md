# Matchcard — оценка футбольного матча

Мобильное веб-приложение для родителя или тренера: после игры (или прямо на поле) записать, как сыграл ребёнок, получить оценку из 10, сохранить историю сезона и поделиться карточкой в мессенджере.

Это не таблица чемпионата и не трекер команды целиком. Один экран — один игрок (можно вести до 32 карточек на телефоне). Счёт матча команды вносится вручную, как фон; оценка считается по действиям и поведению выбранного ребёнка. База **6,0** — это обычный матч, не школьная тройка.

Живая страница: [https://ihormich.github.io/ffk/](https://ihormich.github.io/ffk/)

Локально достаточно открыть `index.html` в браузере (рядом должны лежать `css/` и `js/`). Сервер не нужен. Для установки на домашний экран есть `manifest.webmanifest`.

## Для кого и какую задачу закрывает

Типичный сценарий: детский матч 2×30 или 3×20, родитель стоит у поля, хочет не «ну вроде нормально», а понятную оценку и что сказать после игры.

Приложение:

- считает **вклад** (что сделал на поле) и **старание** (как себя вёл);
- собирает **общую оценку** от 6,0 до 10;
- помнит матчи по **сезонам** (футбольный год с 1 июля);
- рисует **карточки** матча, сезона и периода, чтобы отправить в чат;
- после серии игр показывает **сильные стороны**, зоны развития и короткий «разбор тренера».

Данные живут только в браузере этого телефона (localStorage). Облака, аккаунта и синхронизации между устройствами нет. Перед сменой телефона сохраните копию в настройках.

## Как устроена оценка

База всегда **6,0**. От неё плюсуются игровые действия и (слабее) поведение. Итог обрезается в диапазоне 0–10 с одним знаком после запятой.

На экране матча видны три числа:

| Число | Что это |
| --- | --- |
| **Общая оценка** | Действия + часть старания. Это главное число в шапке, истории и на карточке. |
| **Вклад** | Только игровые действия с учётом позиции. |
| **Старание** | Среднее по шкалам «как играл», без учёта настроения. |

Повтор одного и того же действия весит меньше, чем первое: второй гол слабее первого, десятый сейв почти не двигает оценку. Так сильный, но однообразный матч не раздувается до 10 из-за серии одинаковых плюсов.

Набор кнопок зависит от **позиции**. Для нападающего важны голы, удары, ассисты, обводки, открывания. Для полузащитника — передачи, острые пасы, отборы, единоборства. Для защитника — отборы, перехваты, выносы, блоки; ошибки бьют сильнее. Для вратаря — сейвы, выходы, игра ногами, пропущенные.

Шкалы «как играл» (1–5, по умолчанию 3):

- интенсивность и дуэли;
- игра в команде;
- слушал тренера;
- дисциплина / уважение к арбитру;
- настроение — **в оценку не входит**, это заметка для себя.

Короткий выход со скамейки не меняет формулу, но в тексте разбора учитывается, что минут было мало.

## Вкладки

Внизу четыре вкладки. Шестерёнка в шапке открывает настройки. Иконка солнца/луны переключает светлую и тёмную тему.

### Игрок

Карточка человека, за которым ведёте учёт:

- фото (круглое) и фон-баннер; после выбора кадра можно подвинуть и увеличить фрагмент;
- имя, фамилия, дата рождения, номер, команда, клуб/академия (можно оставить пустым);
- основная позиция и дополнительные;
- текущий сезон: открыть или закрыть.

Можно завести несколько игроков (братья, разные дети в группе) — не больше **32**. У каждого своя история матчей. Переключение в списке «Мои игроки». Удаление игрока стирает и его матчи с телефона; последнего игрока удалить нельзя.

После сохранения данных остаётесь на этой вкладке. Здесь же профиль сезона: средняя оценка, голы и ассисты, тренд последних матчей, сильные стороны и фокус на развитие.

Сезон в формате `2026/27` начинается **1 июля**. Новые матчи пишутся в открытый сезон. Закрытый сезон остаётся в архиве фильтров истории и статистики; можно открыть следующий.

### Матч

Основной рабочий экран. Сверху живая оценка. Ниже — форма и счётчики.

Контекст игры:

- дата;
- тип: чемпионат, товарищеский, кубок, турнир (для всех кроме товарищеского — название соревнования);
- соперник и счёт команды;
- дома / на выезде;
- в старте / со скамейки;
- формат: 3×15, 3×20, 3×25, 2×25, 2×30, 2×35, 2×40, 2×45 или свой (длина до 120 минут);
- минуты **на поле** отдельно от длины матча;
- позиция в этом матче (можно отличаться от основной в карточке).

Дальше плюсы/минусы действий и шкалы поведения, комментарий «что запомнилось», кнопка **Сохранить матч**.

Черновик текущего матча помнится на телефоне, если уйти со страницы не сохранив.

**Быстрый режим** — полноэкранная панель с крупными кнопками тех действий, которые реально жать стоя у поля (не все метрики, только «живые» для позиции). **Старт матча** запускает часы. Часы считают игровое время по выбранному формату (таймы, перерыв, конец). Время для подписей берётся в зоне **Варшава**. Пока часы идут, каждое нажатие пишется в ленту с минутой — из этого потом собирается разбор по таймам. **Готово** возвращает на форму: можно дописать счёт, минуты, комментарий и сохранить.

После сохранения открывается отчёт: оценка, что получилось, фокус на следующий раз, кнопка карточки для мессенджера и «разбор по минутам», если действия ставили после старта часов.

### История

Список сохранённых матчей текущего игрока, фильтр по сезону, по **10 матчей** на страницу.

У каждой записи: дата, соперник, оценка, правка, удаление, снова поделиться карточкой. **Карточка сезона** собирает картинку по выбранному сезону.

### Статистика

Сводка по сезону и выбранному периоду: средняя оценка, лучший и худший матч, минуты, голы, тренд.

График оценок: последние 10, 100 или все матчи.

Сравнение динамики (начало сезона vs конец): рейтинг, обводки, отборы, потери, единоборства.

**Карточка периода**: последние 10 матчей, неделя, месяц, год или всё время.

Если достаточно матчей с записанными минутами, появляется отчёт: в каком тайме чаще польза или брак, не проседает ли концовка.

### Настройки

- язык: украинский, польский, английский, русский, испанский, немецкий, итальянский, французский, португальский;
- пока язык не выбрали вручную, берётся язык телефона;
- экспорт / импорт / «сохранить копию» — единственный способ перенести сезон на другой телефон или сделать резервную копию. В настройках это кнопка **Сохранить копию** (файл уходит в «Поделиться» / Файлы), не нужно разбираться в JSON.

Импорт добавляет матчи, не затирая всё подряд без нужды; дубликаты того же дня приложение может переспросить при сохранении.

## Карточки для мессенджера

Приложение рисует картинку (не текст): фото, оценка, соперник, вклад и старание, ключевые действия. Можно сохранить в галерею или отдать в системный «поделиться», если браузер это умеет.

Есть карточка одного матча, карточка сезона и карточка произвольного периода.

## Что хранится на телефоне и чего нет

Есть:

- карточки игроков (фото тоже, в сжатом виде);
- матчи каждого игрока отдельно;
- настройки, тема, выбранный язык, черновик незакрытого матча, последняя открытая вкладка.

Нет:

- сервера, логина, облака;
- общего кабинета для всей академии;
- автоматической выгрузки в WhatsApp/Telegram — только картинка или JSON.

Если места в localStorage не хватит (обычно из‑за тяжёлых фото), приложение предупредит, что сохранить не удалось.

## Установка на телефон

1. Откройте [страницу на GitHub Pages](https://ihormich.github.io/ffk/) в Safari (iPhone) или Chrome (Android).
2. «На экран Домой» / «Установить приложение».
3. Дальше открывается как обычное приложение, без адресной строки.

Это PWA: офлайн после первого открытия зависит от кэша браузера, но источник правды всё равно localStorage этого устройства.

## Технически

| | |
| --- | --- |
| Стек | `index.html` + `css/app.css` + `js/i18n.js` + `js/rating.js` + `js/storage.js` + `js/app.js`, без сборки |
| Данные | `localStorage` (ключи вида `ffk_*`) |
| Оценка | Формула в браузере, без внешнего API |
| Репозиторий | GitHub Pages отдаёт эти же файлы |

Менять интерфейс — `index.html` и `css/app.css`, тексты — `js/i18n.js`, формулу оценки — `js/rating.js`, сохранение — `js/storage.js`, экраны — `js/app.js`. Отдельного бэкенда и зависимостей нет.

## Android и iPhone

Тот же веб внутри Capacitor. GitHub Pages не трогаем. После правки HTML/CSS/JS:

```
npm install
npm run android
```

или `npm run ios` — откроет Android Studio / Xcode. Debug-сборку запускаете там (нужны JDK + Android SDK или полный Xcode). Данные PWA в Safari и данные приложения — разные хранилища: перенос через «Сохранить копию».
