# FFK — оценка матча

Мобильная страница для оценки игры ребёнка после футбольного матча. Всё считается в браузере, данные хранятся на телефоне.

Откройте `index.html` или страницу GitHub Pages. Перед сменой телефона нажмите **Экспорт** на вкладке «История».

## Что умеет

- Быстрый режим с крупными кнопками на поле
- Оценка стартует с 6.0 и может дойти до 10
- Формат матча: 3×20, 2×30 и свой вариант; минуты на поле отдельно
- Два балла: вклад (действия) и старание (поведение)
- Веса зависят от позиции; повторные голы слабее первого
- Українська / Polski / English / Русский — мова в налаштуваннях (шестерня)
- Карточка матча для мессенджера
- История, правка, экспорт / импорт JSON
