# FFK — оценка матча

Мобильная страница для оценки игры ребёнка после футбольного матча. Всё считается в браузере, данные хранятся на телефоне.

Откройте `index.html` или страницу GitHub Pages. Перед сменой телефона нажмите **Экспорт** на вкладке «История».

## Что умеет

- Оценка с учётом позиции (нападающий, полузащита, защита, вратарь)
- Минуты на поле (для статистики, не ломают балл короткой заменой)
- История, правка и удаление матча
- Экспорт / импорт JSON
- Подсказка после матча: что получилось и на чём сфокусироваться
